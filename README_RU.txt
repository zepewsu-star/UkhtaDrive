UKHTA DRIVE — CGE PROTOTYPE 0.1
================================

Что это
-------
Это первый НЕ-браузерный каркас автомобильного симулятора на Object Pascal
для Castle Game Engine (CGE).

В этой версии уже заложено:
- вид из салона;
- процедурный салон большого седана с рулем и четырьмя кольцами на ступице;
- газ / тормоз / задний ход / руление / ручник;
- скорость, передача, одометр;
- день / ночь;
- уличное освещение ночью;
- зимнее окружение;
- двор, выезд, широкая магистраль, кварталы, припаркованные машины;
- столкновения со зданиями;
- архитектура, в которую дальше подключаются реальные сектора Ухты.

ВАЖНО
------
Текущая геометрия улиц — ПРОТОТИП, а не точная карта Ухты.
Она нужна, чтобы проверить управление, кабину, масштаб и производительность.

Точная Ухта будет следующим слоем:
OpenStreetMap -> сектора -> дороги/дворы/контуры зданий -> ручная детализация.

Audi A6
-------
В архив НЕ включена скачанная откуда-либо модель Audi A6.
Салон сейчас процедурный, чтобы проект не зависел от чужих лицензий.
Архитектура предусматривает замену салона и автомобиля на легально
полученную glTF-модель Audi A6 C7 без переписывания симулятора.

Управление
----------
W - газ
S - тормоз / задний ход после остановки
A / D - руль
SPACE - ручник
R - вернуть машину во двор
N - день / ночь
H - скрыть подсказку
P - сделать screenshot

Как собрать без Delphi
----------------------
Castle Game Engine уже поставляется с Free Pascal.

Вариант 1:
1. Скачайте Castle Game Engine.
2. Откройте CastleEngineManifest.xml в Castle Game Engine Editor.
3. Run -> Compile And Run.

Вариант 2:
из командной строки в каталоге проекта:
  castle-engine compile
  castle-engine run

Windows x64:
  castle-engine package --os=win64 --cpu=x86_64

GitHub Actions
--------------
В архиве есть:
.github/workflows/build.yml

После загрузки проекта в GitHub Actions автоматически соберет Windows x64.
Delphi на вашем компьютере не требуется.
