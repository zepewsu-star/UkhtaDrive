PARMA INVEST · Android Native v0.9
================================
Это отдельная тестовая сборка на чистом Android SDK (Java, не WebView и не PWA).
Приложение читает действующий защищенный API панели по HTTPS, без изменений сервера, Cron или БД.

Авторизация: пароль панели вводится при каждом новом запуске, хранится только в оперативной памяти; в APK пароля нет.
Функции: «Обзор» (GOLD, LQDT, SBER, ABIO), «Аналитика» (кандидаты наблюдения),
«Система» (состояние памяти, история, Cron), кнопка обновления.

Реальные покупки, push, портфель не реализованы; исследования не признаны надёжными.
Тестовая сборка устанавливается рядом с прежней, appId ru.parma.invest.client.
Сборка: gradle -p ParmaInvestNative assembleDebug (JDK 17, SDK 35, Gradle 8.9).
GitHub Actions: workflow «Build Parma Invest Native APK».


Версия v0.9.3 — вход по отпечатку
================================
- Первый вход по паролю панели; в приложении предложено включить отпечаток.
- Подтверждение отпечатка шифрует пароль через Android Keystore AES-256-GCM.
- Хранится только зашифрованный пароль; ключ привязан к сильной биометрии (Android 11+).
- При следующем запуске и после возвращения из фона нужен отпечаток; пароль всегда остаётся запасным способом.
- При изменении отпечатков ключ автоматически недействителен. Вход по паролю позволяет настроить снова.
- В разделе «Система» отпечаток можно включить, переустановить или отключить.
- Сервер, Cron и база данных не меняются. Реальных торговых функций нет.

PARMA INVEST Android v0.10.0 — исследовательский радар
======================================================
- Новая вкладка «Сигналы» получает реальные данные из API панели action=market.
- Отображаются максимум 14 инструментов с качеством ok из первых 180, возвращённых сервером.
- По нажатию «Исследовать уровни» загружается до 90 дневных свечей выбранного инструмента (action=series).
- Зона наблюдения: минимум последних 20 закрытий до +3% от него; тренд — средняя 20 >= средняя 60.
- Исторический риск: максимальная просадка по закрытиям за последние 60 сессий.
- Уровень поддержки и сопротивления — исторические ориентиры, не цены сделок.
- 6–12-месячная доходность и реальная торговая рекомендация НЕ рассчитываются.
- Отображение с проверкой свежести дат и качества данных; нет сигналов при устаревшей истории.
- Не сканирует весь каталог (API возвращает первые 180). Подключение полного рынка — последующее расширение сервера.
- Никаких запросов на покупку/продажу, push, SQL, CRON или правок сервера.
- Существующий вход по отпечатку, иконка и системные отступы сохранены.
